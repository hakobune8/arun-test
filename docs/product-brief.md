# Product Brief: Echo Echo

## 概要

**Echo Echo** は、視覚パターンと音高を連動させるミニマルなパズルゲームです。プレイヤーは画面に表示される視覚パターンを「音」として認識し、正しい音階にマッチさせることでレベルをクリアします。

## 対象ユーザー

- 短時間のプレイを好むカジュアルゲーマー
- 視覚と聴覚の連動体験に興味を持つユーザー
- 1回3〜5分で完結するミニマルゲームを好む層

## コアループ（主要ワークフロー）

1. **提示**: 画面に視覚パターン（色・形状・配置）が表示される
2. **認識**: プレイヤーは視覚パターンを音高として解釈する
3. **選択**: 表示された音階ボタンから正しいものを選択
4. **フィードバック**: 正解/不正解の視覚・聴覚フィードバック
5. **進行**: 正解すると次のレベルへ、不正解はヒント表示

## 差別化メカニクス（必須実装項目）

### 視覚共感覚（Visual Synesthesia）

プレイヤーは画面の視覚パターンを「音」として認識する必要があります。これは単なるラベル変更ではなく、以下の observable behavior として実装されます：

- 視覚パターン（色・形状・配置）が特定の音高にマッピングされる
- プレイヤーは視覚情報だけで音高を推測する必要がある
- 正解時に視覚パターンが音として「再生」される（視覚→聴覚のフィードバックループ）

**Observable Criteria（レビュー基準）:**
- [ ] 画面に表示される視覚パターンが音高と1対1で対応している
- [ ] プレイヤーは視覚パターンを「音」として認識するUIを提供されている
- [ ] 正解時に視覚パターンが音として再生されるフィードバックがある
- [ ] 不正解時に視覚パターンが音として再生されるフィードバックがある

## 定性的要求のobservable変換

| 定性要求 | Observable Criteria |
|---------|-------------------|
| 新規性 | 視覚パターン→音高の連動メカニクスが実装されている |
| 楽しい | フィードバック（視覚・聴覚）が即時かつ明確 |
| シンプル | 1画面で完結、操作はボタンクリックのみ |
| 新規性 | 視覚共感覚メカニクスがUI/ソースコードに実装されている |

## Non-Goals（このスプリントで目指さないもの）

- 複数プレイヤー対応
- 外部サービス連携
- 複雑なストーリー展開
- 高品質な音楽制作
- 複数デバイス間セーブデータ同期

## Sprint 1 受入基準

- [ ] `GET /` でゲームタイトル画面が表示される
- [ ] `GET /play` でゲームプレイ画面が表示される
- [ ] 視覚パターンと音高の対応が少なくとも3レベルで実装されている
- [ ] 正解/不正解の視覚・聴覚フィードバックが表示される
- [ ] `GET /health` で `200 OK` が返る
- [ ] `go test ./...` が全テストパス
- [ ] `docker build` が成功し、`docker run` でサーバー起動可能
- [ ] `helm template` がエラーなく出力される

## 技術スタック

- **Backend**: Go (net/http)
- **Frontend**: HTML/CSS/JS (static files)
- **Container**: Docker
- **Deployment**: Helm/Kubernetes
