# Gravity Invaders - Product Brief

## 概要
「新規性のあるインベーダーゲーム」の要望に応え、古典的なインベーダーゲームに「重力反転（Gravity Flip）」という差別化メカニクスを追加した、シンプルで遊びやすいブラウザゲームです。

## 対象ユーザー
- レトロゲームやアーケードゲームを気軽に楽しみたいユーザー
- 短時間で遊べるカジュアルゲームを好むユーザー
- シンプルな操作で直感的なゲーム体験を求めるユーザー

## コアループ（主要ワークフロー）
1. プレイヤーは画面下部の自機を左右に移動させる。
2. 画面上部の敵が左右に移動しながら降下してくる。
3. プレイヤーは自機から弾を発射して敵を破壊する。
4. 敵が画面下部に到達するか、自機に衝突するとゲームオーバー。
5. **差別化メカニクス**: プレイヤーはスペースキー（またはクリック）で「重力反転」を発動し、自機の位置を画面下部から上部に瞬時に移動させることができる。これにより、敵の弾を回避したり、敵の背後に回り込んだりして攻撃できる。

## 差別化メカニクス（Gravity Flip）
- **実装要件**: UIまたはソースコード上で、重力反転の視覚的フィードバック（自機の移動アニメーション、画面の反転エフェクトなど）と、反転後の操作感（自機が画面上部で敵を攻撃する状態）が明確に実装されること。
- **observable criteria**: 
  - スペースキー押下で自機が画面下部から上部へ瞬時に移動する。
  - 移動中に無敵状態になる（敵の弾や衝突から守られる）。
  - 反転後は自機が画面上部で敵を攻撃できる状態になる。
  - 一定時間経過または別の操作で元の位置へ戻る。

## 定性的意図のobservable criteria
- **新規性（Novelty）**: 重力反転メカニクスが実装され、従来のインベーダーゲームとは異なる戦略的要素が提供される。
- **楽しい（Playful）**: 重力反転時のアニメーションやエフェクトが滑らかで、操作に対するフィードバックが明確。
- **シンプル（Simple）**: 操作は左右移動、発射、重力反転の3つのみ。UIは直感的で、複雑な設定や説明不要。
- **production-ready**: エラーハンドリングが適切で、ブラウザで安定して動作し、レスポンシブデザインに対応。

## Non-goals
- マルチプレイヤー機能
- 複雑なストーリーやキャラクター設定
- 外部サービスとの連携（スコアランキングなど）
- 高度なグラフィックスや3D表現

## Sprint 1 受入基準（Acceptance Criteria）
- [ ] 自機が左右に移動可能
- [ ] 自機から弾を発射可能
- [ ] 敵が左右に移動しながら降下
- [ ] 弾が敵に衝突すると敵が破壊され、スコア加算
- [ ] 重力反転メカニクスが実装され、自機が画面上下で移動可能
- [ ] 敵が画面下部に到達または自機に衝突するとゲームオーバー
- [ ] ゲームオーバー後、リスタート可能
- [ ] レスポンシブデザインでブラウザ上で動作
- [ ] DockerfileとHelm chartでコンテナ化可能
- [ ] GitHub Actions CIでテストとビルドが実行可能
