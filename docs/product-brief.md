# プロダクトブリーフ: フェーズシフト・インベーダー

## 概要
従来のインベーダーゲームに**「フェーズシフト（位相変化）」**という差別化メカニクスを追加し、敵の弾を回避しながら攻撃タイミングを計る戦略的なプレイを提供する。外部サービスに依存せず、ローカルおよびKubernetes環境で安定して動作するミニマルなWebベースのアーケードゲーム。

## 対象ユーザー
- レトロゲームやアーケードゲームを好むカジュアルゲーマー
- シンプルな操作感でありながら、奥深い戦略性を求めるプレイヤー
- 短時間で遊べるが、高得点やコンボを狙えるゲームを求めているユーザー

## コアループ / 主要ワークフロー
1. **フェーズ選択**: プレイヤーは「実体フェーズ」と「幻影フェーズ」の2つの状態から選択できる。
2. **移動と回避**: 敵の弾を「実体フェーズ」では回避し、「幻影フェーズ」ではすり抜ける（または敵と共存する）。
3. **攻撃**: 敵を「実体フェーズ」で撃つと倒せるが、幻影フェーズでは攻撃が通らない。敵の配置や弾の軌道に合わせてフェーズを切り替えながら攻撃する。
4. **スコア計算**: 連続でフェーズを切り替えずに攻撃を成功させるとコンボボーナスが付く。

## 差別化メカニクス: フェーズシフト
- **実体フェーズ**: 通常のインベーダーゲームと同様。敵を撃てて倒せるが、敵の弾に当たるとダメージを受ける。
- **幻影フェーズ**: 敵の弾をすり抜けられるが、プレイヤーの弾は敵に当たらない。敵はプレイヤーを通過するだけで攻撃してこない（または攻撃が弱体化する）。
- **切り替えコスト**: フェーズを切り替えるにはクールタイムまたはリソース消費がある。無制限な切り替えは不可能であり、タイミングが重要。

## 定性的要件の観測可能な基準
- **新規性**: 従来のインベーダーゲームには存在しない「フェーズシフト」メカニクスが実装されており、UI上で現在のフェーズが明確に視覚的に区別できる。
- **楽しい**: フェーズ切り替えによる回避と攻撃の切り替えが直感的に理解でき、コンボボーナスや高得点のフィードバックが明確にある。
- **シンプル**: 操作はキーボードの矢印キー（移動）とスペースキー（攻撃）、Shiftキー（フェーズシフト）の3つに限定されている。UIは最小限の表示に留める。
- **production-ready**: エラーハンドリングが適切に行われており、ローカル環境で安定して動作し、Docker/Kubernetes環境でも正常に起動・応答する。

## 非目標 (Non-goals)
- 複数プレイヤーのオンライン対戦
- 複雑なストーリーモードやキャラクター育成
- 高解像度の3Dグラフィックスや複雑なエフェクト
- 外部サービスへの依存（認証、スコアランキングなど）
