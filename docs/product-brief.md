# Neon Drift Invaders — Product Brief

## Concept

**Neon Drift Invaders** は、インベーダーゲームの古典的なコアに「慣性ドリフト」メカニクスを組み合わせた、アーケードスタイルのブラウザゲームです。プレイヤーは慣性（モメンタム）を持つ宇宙船を操作し、敵弾を回避しながら敵を撃破します。

## Target User

- ブラウザで即座にプレイできるカジュアルアーケードゲームを好むユーザー
- シンプルな操作だが、スキルが試されるゲームを好むプレイヤー
- 30秒〜数分のプレイセッションを想定

## Core Loop

1. **移動**: 矢印キーまたはA/Dキーで宇宙船を操作。慣性により、キーを離しても船は滑らかに減速する
2. **射撃**: スペースキーで弾を発射
3. **回避**: 敵の弾をドリフトしながら回避。慣性による滑らかな移動が回避の鍵
4. **スコア**: 敵を撃破するとスコア加算。連続撃破でコンボボーナス
5. **ライフ**: 敵弾に当たるとライフ減少。ライフ0でゲームオーバー
6. **レベルアップ**: 敵を全滅させると次のレベルへ。敵の速度・弾の頻度が上昇

## Differentiating Mechanic: 慣性ドリフト

### 実装仕様

- プレイヤー船の移動に物理的な慣性を実装
  - キー入力時に加速度が付与される
  - キーを離すと減速係数（0.92）で滑らかに減速
  - 最大速度制限あり
- 敵の移動にも微かな慣性を実装（より有機的な動き）
- 弾は直進（慣性なし）— プレイヤーの移動予測が重要

### 差別化ポイント

| 従来のインベーダー | Neon Drift Invaders |
|---|---|
| 即座に停止・方向転換 | 慣性による滑らかな移動 |
| 弾は直進 | 弾は直進（プレイヤーの移動予測が必要） |
| 位置取りは静的 | 位置取りは動的（モメンタム管理） |

## Observable Acceptance Criteria

### AC-1: 慣性ドリフトの動作
- [ ] プレイヤーが右キーを押すと、船が加速して移動する
- [ ] プレイヤーがキーを離すと、船は即座に停止せず、滑らかに減速する
- [ ] 減速係数は 0.92 前後で、自然な減速感がある
- [ ] 最大速度を超えない（速度制限が機能する）

### AC-2: シンプルな操作
- [ ] 矢印キー（上下左右）で移動可能
- [ ] スペースキーで射撃可能
- [ ] A/Dキーでも左右移動可能（代替入力）
- [ ] Wキーでも射撃可能（代替入力）

### AC-3: ゲームフロー
- [ ] スタート画面からゲーム開始可能
- [ ] ゲームオーバー画面でスコア表示とリトライ可能
- [ ] レベルクリア時に次のレベルへ自動遷移
- [ ] ライフ表示とスコア表示が画面に表示される

### AC-4: ビジュアル
- [ ] ネオン風の発光エフェクト（CSS glow / Canvas shadow）
- [ ] 敵の撃破時にエフェクト（パーティクルまたは点滅）
- [ ] プレイヤー船と敵の区別が明確

### AC-5: パフォーマンス
- [ ] 60fps での動作（Canvas レンダリング）
- [ ] ブラウザのメモリリークなし（GC 対象のオブジェクトが適切に破棄される）

## Non-Goals (Sprint 1)

- サウンドエフェクト・BGM
- ハイスコアの永続化（ローカルストレージ以外）
- マルチプレイヤー
- モバイルタッチ操作
- 敵の複雑な行動パターン（Sprint 2 以降）
- 外部サービス連携

## QA Validation

1. ブラウザで `http://localhost:8080` にアクセスし、ゲームが起動すること
2. 矢印キーで移動し、慣性による滑らかな減速を確認すること
3. スペースキーで射撃し、敵を撃破できること
4. 敵弾に当たるとライフが減少すること
5. ゲームオーバー画面でスコアが表示され、リトライできること
6. 30秒間のプレイでメモリリークがないことを確認すること
