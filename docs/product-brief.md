# Product Brief: Ricochet Invaders

## 概要
クラシックなインベーダーゲームに「リコシェット（跳ね返り）弾」メカニクスを追加し、戦略性と新規性を持たせたアーケードゲーム。

## 対象ユーザー
- クラシックなアーケードゲームを好むカジュアルゲーマー
- シンプルな操作で楽しめるが、戦略的な要素も求めているユーザー

## コアループ / 主要ワークフロー
1. プレイヤーは画面上部の敵陣を攻撃するために、画面下部で左右に移動し、弾を発射する。
2. 発射された弾は画面の壁や敵に当たると跳ね返り（リコシェット）、直接照準が合わない敵や背後の敵にもダメージを与えられる。
3. 敵を全滅させると次のウェーブへ進み、敵の移動速度や配置が変化する。
4. 敵が画面下部に到達するか、プレイヤーのライフが0になるとゲームオーバー。

## 差別化メカニクス: リコシェット弾
- **定義:** 弾が画面端や敵に衝突すると、特定の角度で跳ね返る。
- **観測可能な動作:**
  - 弾が壁に当たると反射する。
  - 弾が敵に当たると、敵は破壊され、弾は別の方向へ跳ね返る。
  - プレイヤーは跳ね返りを予測して、隠れた敵や密集した敵を効率的に攻撃できる。
- **新規性の可視化:** 従来の直進弾とは異なる弾の軌道アニメーションと、跳ね返りによる戦略的な攻撃パスの可視化。

## 定性的要件の観測可能な基準
- **新規性:** リコシェット弾の物理挙動が実装され、従来のインベーダーゲームとは異なるプレイ体験を提供する。
- **楽しい:** 弾の跳ね返りによる予期せぬヒットや、戦略的な配置破壊がプレイヤーに達成感を与える。
- **シンプル:** 操作は左右移動と発射のみ。UIは直感的で、複雑なメニューや設定を排除する。
- **ポップ:** 鮮やかな色彩とシンプルな几何学的な敵デザインを採用し、アーケード感を演出する。
- **Production-ready:** フレッシュなチェックアウトから `go run ./...` でローカル実行可能。DockerビルドとHelmテンプレート化が正常に動作する。

## 非目標 (Non-goals)
- マルチプレイヤー機能
- 複雑なパワーアップシステム
- ナラティブ駆動のキャンペーンモード
- 高スコアリーダーボード（Sprint 1ではローカルスコアのみ）

## Sprint 1 受入基準 (Acceptance Criteria)
- [ ] プレイヤーが左右に移動し、弾を発射できる。
- [ ] 弾が画面の壁と敵に衝突し、跳ね返る挙動が実装されている。
- [ ] 敵がクラシックな陣形で移動し、徐々に下降する。
- [ ] 敵が画面下部に到達するか、プレイヤーのライフが0になるとゲームオーバー画面が表示される。
- [ ] 敵を破壊するとスコアが加算され、スコア表示が更新される。
- [ ] ゲームはモダンブラウザでレスポンシブに表示され、キーボード操作でプレイ可能。
- [ ] `go build ./...` と `go test ./...` が成功し、エラーがない。
- [ ] Dockerイメージが正常にビルドされ、ローカルで起動できる。
- [ ] Helmチャートが `helm template` で正常にテンプレート化される。
