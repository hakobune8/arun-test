# Product Brief: リズム・インベーダー (Rhythm Invaders)

## 1. 概要

**タイトル**: リズム・インベーダー (Rhythm Invaders)
**コンセプト**: 音楽のビートに合わせて敵を撃つ、新規性のあるインベーダーゲーム。
**対象ユーザー**: アーケードゲームやリズムゲームを好むカジュアルゲーマー、Go言語によるWebアプリケーション開発の検証者。

## 2. コアループ (Core Loop)

1. **ビート感知**: ゲーム画面下部から流れるビジュアルリズムゲージ（またはBGM）の拍子（ビート）をユーザーが確認する。
2. **タイミング入力**: ビートに合わせてスペースキー（またはクリック）で弾を発射する。
3. **スコア計算**: ビートとタイミングが一致しているほど高いスコア（コンボ）が加算され、敵が倒れる。
4. **フェーズ進行**: 敵の出現パターンやBGMのテンポが上昇し、難易度が段階的に高まる。

## 3. 差別化メカニクス (Differentiating Mechanic)

**ビート同期型発射 (Beat-Synced Shooting)**:
- 従来のインベーダーゲームが「敵の位置に合わせて撃つ」のが主流であるのに対し、本作は「音楽の拍子に合わせて撃つ」ことを主軸とする。
- 画面下部にビジュアルフィードバック（例：拍子に合わせて点滅するゲージ）を表示し、ユーザーが直感的にタイミングを掴めるようにする。
- 正確なタイミングで撃つほど敵が弱体化し、一撃で倒せる仕組みを実装する。

## 4. 定性的要件のobservable criteriaへの変換

| 定性的意図 | Observable Criteria (検証可能な基準) |
| :--- | :--- |
| **新規性 (Novelty)** | 弾を発射するタイミングが、画面下部のビートゲージの点滅タイミングと連動していること。 |
| **楽しい (Playful)** | コンボが繋がると、画面エフェクトやスコア表示が派手になり、ユーザーに達成感を与えること。 |
| **シンプル (Simple)** | 操作は「スペースキー」または「マウスクリック」の1つのみで、ルール説明が3文以内で完結すること。 |
| **Production-ready** | Dockerコンテナ内で起動し、`/health`エンドポイントが正常応答すること。HelmチャートでK8sにデプロイ可能であること。 |

## 5. Non-goals (今回のスプリントで目指さないこと)

- 複数プレイヤーによるオンライン対戦機能。
- 複雑なストーリーモードやキャラクター育成システム。
- 外部の音楽配信サービスとの連携。
- モバイルデバイスへの完全なタッチ操作最適化（まずはデスクトップブラウザをターゲットとする）。

## 6. Sprint 1 Acceptance Criteria

1. **最小限の動作**: `go run` または Docker コンテナ起動後、ブラウザで `/` にアクセスするとゲーム画面（CanvasまたはDOMベース）が表示されること。
2. **ビート同期メカニクス**: 画面下部にビートが可視化され、ユーザーが操作（発射）できるタイミングを示すこと。
3. **基本的なゲームループ**: 敵が画面上部から出現し、ユーザーの発射により倒せること。スコアが加算されること。
4. **ヘルスチェック**: `/health` エンドポイントが `200 OK` を返すこと。
5. **ドキュメント整合性**: `README.md` と `docs/product-brief.md` が同じコンセプト（リズム・インベーダー）を指していること。
