# 新規性のあるインベーダーゲーム — Product Brief

## 概要

**製品名:** Rhythm Invaders（リズムインベーダー）

インベーダーゲームの古典的なコアループに「リズム同期」という差別化メカニクスを追加し、リズムゲームとシューティングの融合体験を提供する。

## 対象ユーザー

- インベーダーゲームの基本的な楽しさは理解しているが、既存タイトルに飽きているプレイヤー
- リズムゲームや音楽に親しんだカジュアルゲーマー
- ブラウザで手軽に遊べるミニマルなゲームを求めているユーザー

## コアループ（主要ワークフロー）

1. **敵の出現**: バックグラウンドのビートに合わせて敵が波状に出現する
2. **リズム同期攻撃**: ビート（拍子）に合わせて発射すると「タイミングボーナス」が加算される
3. **スコア計算**: 基本スコア + タイミング精度ボーナスで総合スコアを算出
4. **フェーズ進行**: 敵の出現パターンとビートテンポが段階的に変化

## 差別化メカニクス: リズム同期（Rhythm Sync）

### 定義

敵の出現とプレイヤーの攻撃にリズム（ビート）を同期させる。ビートに合わせて発射すると、タイミング精度に応じてボーナススコアが加算される。

### 実装要件（コード/UI に現れること）

- ゲームループ内に BPM（Beats Per Minute）管理ロジックが存在する
- ビートに合わせて画面に視覚的フィードバック（例: 拍子を示すインジケーター、エフェクト）が表示される
- 発射タイミングとビートとの時間差を計算し、精度に応じたスコアボーナスを適用するロジックが存在する
- 少なくとも 2 種類のビートパターン（例: 4/4拍子、8分音符パターン）が実装される

### 定性的要件の観測可能基準

| 定性的意図 | 観測可能基準 |
|------------|-------------|
| 新規性 | リズム同期メカニクスが実装され、ビートと攻撃の連動がゲームプレイの中心にある |
| 楽しい | タイミングボーナスのフィードバック（スコア表示、視覚効果）が明確で、プレイヤーがタイミングを計れる |
| シンプル | 操作は矢印キー（移動）とスペースキー（発射）のみ。UI は敵、弾、スコア、ビートインジケーターに限定 |
| 生産準備完了 | ローカルで `go run` してブラウザでアクセス可能。Docker コンテナ化済み。Helm chart で K8s デプロイ可能 |

## 非目標（Non-goals）

- 複数プレイヤー対応（ローカル/オンラインマルチプレイ）
- 外部サービス連携（スコア共有、リーダーボード）
- 複雑なストーリーやキャラクター設定
- モバイルタッチ操作最適化
- 本格的なサウンドエフェクト（ビートは Web Audio API で生成）
