# Gravity Invaders — Product Brief

## Concept

**Gravity Invaders**は、プレイヤーが「重力フィールド」を操作できるインベーダーゲームです。敵弾を重力で曲げて回避・反射させ、自機の位置だけでなく「重力の向き」自体が戦略の中心になります。

## Target Users

- シンプルな操作で直感的に遊べるゲームを好むカジュアルゲーマー
- 従来のインベーダーゲームに飽きた中・上級者
- 1〜2分のセッションで遊べるミニゲームを好むユーザー

## Core Loop

1. **敵の出現** — 画面上部から敵が降下してくる
2. **重力操作** — マウス/タッチで重力の中心を移動（敵弾が重力に引かれる）
3. **弾の回避・利用** — 重力で敵弾を曲げて回避、または敵に反射させて破壊
4. **スコア獲得** — 敵を倒す、敵弾を反射で破壊する、コンボを繋げる
5. **難易度上昇** — 敵の速度・弾の数・重力の強さが段階的に増加

## Differentiating Mechanics

### 1. 重力フィールド（核心 mechanic）
- プレイヤーはマウス/タッチで画面内の「重力の中心」を移動できる
- 敵弾は重力の中心に向かって曲がって飛ぶ
- 自機は重力の影響を**受けず**、自由に移動可能
- 敵弾を重力で曲げて敵にぶつけることで「反射破壊」が可能

### 2. 反射破壊ボーナス
- 敵弾を敵に反射させて破壊すると通常より2倍のスコア
- 連続反射でコンボボーナス

### 3. 重力スピン（特殊スキル）
- スペースキーで「重力スピン」発動（クールダウンあり）
- 画面内の全敵弾を逆方向に巻き戻す
- 緊急回避や大規模反射に使用

## Acceptance Criteria

| 番号 | 要件 | 検証方法 |
|------|------|----------|
| AC-1 | 重力フィールドがマウス/タッチで操作可能 | ブラウザでマウス移動時に重力中心が追従する |
| AC-2 | 敵弾が重力の影響を受けて曲がる | 敵弾の軌道が重力中心に向かって曲がることを確認 |
| AC-3 | 自機は重力の影響を受けない | 自機はマウス位置に正確に追従 |
| AC-4 | 反射破壊で2倍スコア | 反射破壊時に通常破壊の2倍のスコアが表示される |
| AC-5 | 重力スピンがクールダウン付きで発動可能 | スペースキーで発動、クールダウン中は使用不可 |
| AC-6 | ゲームオーバー条件が明確 | 自機が敵弾に当たるとゲームオーバー画面へ遷移 |
| AC-7 | 1画面で完結する | 外部リソースなしでブラウザで完結して動作 |

## Non-Goals

- 複数プレイヤー対応
- 外部サービス連携（スコアランキング等）
- 複雑なストーリーモード
- モバイルネイティブアプリ（ブラウザ対応のみ）
- 3Dグラフィックス

## Quality Translation

| 定性的要求 | 観測可能な基準 |
|------------|----------------|
| 新規性 | 重力で弾を操作する mechanic が実装され、従来のインベーダーと明確に異なる |
| 楽しい | 反射破壊のコンボが繋がり、スコアが上昇するフィードバックがある |
| ポップ | 敵弾の軌道が視覚的に分かりやすく、重力フィールドの位置が明確に表示される |
| シンプル | 操作はマウス移動＋クリック＋スペースキーのみ |
| Production-ready | 外部依存なし、ブラウザで直接動作、エラーなく起動 |
