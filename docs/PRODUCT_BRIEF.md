# プロダクト設計ブリーフ

## 製品名
**Gravity Invaders**（重力インベーダー）

## 対象ユーザー
- シンプルなアーケードゲームを好むカジュアルゲーマー
- 従来のインベーダーゲームのメカニクスを知りつつ、新しい戦略要素を求めるプレイヤー
- 短時間で遊べるが、奥深いゲーム性を求めるユーザー

## コア体験
プレイヤーは画面下部の自機を操作し、上から降ってくる敵インベーダーを撃破する。従来のインベーダーゲームとの決定的な違いは、**重力フィールドメカニクス**にある。

### コアループ
1. **自機の配置** — 矢印キーで左右に移動
2. **敵の出現** — 敵が画面下部に到達する前に撃破する必要がある
3. **重力フィールドの配置** — 自機から重力フィールドを配置可能（スペースキー）
4. **連鎖衝突** — 重力フィールドに引き寄せられた敵同士が衝突し、連鎖的に爆発する
5. **スコア加算** — 連鎖数に応じてボーナススコアが付与される
6. **次の波へ** — 全敵撃破で次の波へ（敵の速度・配置パターンが変化）

## 差別化メカニクス: 重力フィールドによる連鎖衝突

### 実装仕様
- プレイヤーはスペースキーで重力フィールドを配置（画面に1つまで同時配置可能）
- 重力フィールドは半径100pxの範囲で敵を中央に引き寄せる
- 引き寄せられた敵同士が接触すると衝突判定が発生し、両方が爆発する
- 1つの衝突が他の敵を連鎖的に引き寄せる可能性があり、連鎖数に応じてスコアが指数関数的に増加
- 重力フィールドは5秒間持続し、その後消滅する

### 観察可能な基準
- [ ] 重力フィールドを配置すると、画面内の敵がフィールド中心へ引き寄せられる
- [ ] 敵同士が接触すると爆発エフェクトが発生し、スコアに加算される
- [ ] 連鎖衝突が発生した場合、連鎖数に応じたボーナススコアが表示される
- [ ] 重力フィールドは5秒間持続し、その後消滅する
- [ ] 画面に複数の重力フィールドを同時に配置できない

## Acceptance Criteria

### Sprint 1
- [ ] Go HTTPサーバーが起動し、`/`パスでゲーム画面がブラウザで表示される
- [ ] 自機が矢印キーで左右に移動可能
- [ ] 敵が画面から降ってくる
- [ ] 自機から弾を発射可能（クリックまたはZキー）
- [ ] 弾が敵に当たると敵が爆発し、スコアに加算される
- [ ] 重力フィールドを配置可能（スペースキー）
- [ ] 重力フィールドが敵を引き寄せ、衝突による連鎖爆発が発生する
- [ ] ヘルスエンドポイント（`/health`）が正常に動作する
- [ ] ゲームタイトル「Gravity Invaders」が画面に表示される

### Sprint 2
- [ ] 複数の敵波が存在し、難易度が上昇する
- [ ] スコア表示とハイスコアの記録（localStorage）
- [ ] ゲームオーバー条件（自機が敵に接触、または敵が画面下部に到達）
- [ ] ゲーム開始・再開のUI

### Sprint 3
- [ ] パフォーマンス最適化（60FPS維持）
- [ ] サウンドエフェクト（Web Audio API）
- [ ] レスポンシブ対応

## Non-goals
- マルチプレイヤー機能
- 外部サービスとの連携（スコア共有など）
- モバイルタッチ操作（Sprint 1では対象外）
- 複雑なキャラクターカスタマイズ
- 本格的なストーリーモード

## 技術スタック
- **Backend**: Go（標準ライブラリのnet/http）
- **Frontend**: Vanilla JavaScript + HTML5 Canvas
- **ビルド**: 標準Goツールチェーン
- **コンテナ**: Docker
- **デプロイ**: Kubernetes（Helm chart）

## 品質基準
- 「新規性」→ 重力フィールドによる連鎖衝突メカニクスが実装され、観察可能である
- 「楽しい」→ 連鎖衝突が意図的に発生し、プレイヤーが戦略的に配置できる
- 「シンプル」→ 操作は矢印キー（移動）、クリック/Z（弾発射）、スペース（重力フィールド）の3種類
- "production-ready" → ヘルスチェック、Dockerビルド、Kubernetesマニフェストが動作する
