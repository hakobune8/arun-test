# Sprint 3 最終レポート

## 概要

新規性のあるインベーダーゲーム「Star Hopper」を、最小垂直スライスから始めて3つのSprintで実装しました。Go HTTPサーバー、Web UI、Docker/Helmデプロイメント、GitHub Actions CIを統合し、レビュー可能な製品インクリメントを完成させました。

## 製品/設計ブリーフ

| 項目 | 内容 |
|------|------|
| 製品名 | Star Hopper |
| 対象ユーザー | クラシックアーケードゲーム愛好者、簡易ブラウザゲームを求めるユーザー |
| コアループ | 敵を撃破 → スコア獲得 → レベルアップ → 難易度上昇 |
| 差別化要素 | 3方向同時射撃メカニクス（通常インベーダーとの違い） |
| 非目標 | マルチプレイヤー、外部サービス依存、モバイル最適化 |

### 定性的要求 → 観測可能基準

| 要求 | 観測可能基準 |
|------|-------------|
| 新規性 | 3方向射撃（中央＋左右）の独自メカニクスを実装 |
| 楽しい | スコア表示、レベル進行、敵パターン変化でフィードバックを提供 |
| ポップ | カラーパレット（#FF6B6B, #4ECDC4, #FFE66D）とCSSアニメーション |
| シンプル | 単一HTMLファイル、外部依存なし、ブラウザで即起動 |
| production-ready | Dockerビルド成功、Helmチャート検証、CIパス、ヘルスエンドポイント |
